Privacy notice.

This notice describes the intended behavior of this fictional, static portfolio demonstration. It is not legal advice or a policy for a real business.

The demo inquiry form does not transmit or store submissions. If this project is modified, hosted, or connected to other services, its actual data practices may differ and must be reviewed separately.

Information entered on this site

The inquiry form asks for sample company, contact, country, product, quantity, and message details to demonstrate client-side form validation. Submission displays a local confirmation and resets the form. This implementation does not send the entries to a server or save them in a database, browser storage, or analytics system.

How information is used

In this demo, entered values are used only within the current page to satisfy required-field validation. No real inquiry is received, reviewed, or acted upon.

Storage and security

The application code does not persist form contents. A static site host or local development server may independently process standard technical request logs; consult the operator of the environment where the demo is hosted for information about those logs and applicable safeguards.

Cookies, analytics, and third parties

This project does not intentionally set cookies, include analytics, or submit form values to third-party services. If additional services are introduced, this statement must be updated to accurately describe them.

Retention and user choices

Because the form does not store submissions, the demo itself has no inquiry records to retrieve or delete. Any data held by a hosting provider or a separately added service is governed by that provider's practices.

Contact and policy review

Garment Works is a fictional name, and no real privacy contact is provided. A real deployment should replace this notice with a reviewed policy, valid contact details, and disclosures that match its actual data flows.
